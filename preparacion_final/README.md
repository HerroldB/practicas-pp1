# Preparación para el final oral

El 16 de octubre la profe envió los módulos de PP1 para preparar el final. En otro correo indicó que las preguntas del oral se basan en los módulos reducidos y recomendó leerlos todos.

Las respuestas de `respuestas_practicas.md` son apuntes de las consignas que fui trabajando. La profe aclaró que las actividades optativas no formaban parte del Trabajo Integrador. Las prácticas de Iris y Titanic están acá como ejercicios de los módulos, no como parte del proyecto de concentración delictiva.

## Archivos

- `respuestas_practicas.md`: respuestas breves y términos para repasar.
- `notebooks/iris_modulo_ii.ipynb`: ejercicio elegido para revisar medidas de flores Iris y compararlas con su especie.
- `notebooks/01_titanic_basico.ipynb`: práctico de Titanic del módulo IV, con revisión de datos, limpieza, dos modelos y una matriz de confusión.
- `grafico_largo_petalo.svg`: gráfico que guarda el notebook de Iris.

El práctico de Titanic descarga un CSV público y necesita conexión a Internet. En el práctico también agregué una función sencilla con `def` para resumir las columnas numéricas, como pide una de las preguntas del módulo IV.
